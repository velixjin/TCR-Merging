# Project page

Source of the project page for *Trajectory-Calibrated Merging of Embodied Policies*, served with GitHub Pages from this
branch. The code is on the [`main` branch](https://github.com/velixjin/TCR-Merging).

Preview locally with `python3 -m http.server` in this directory.

Equations are compiled from the paper with pdfLaTeX and exported as SVG. Fonts in `static/fonts/` (Inter, Source Sans 3,
Source Serif 4) are under the SIL Open Font License 1.1, see `static/fonts/OFL.txt`.
